## Verified findings affecting the first implementation

- **F23:** `src/plant-projection.js` on sim main returns immediately for `subject`; other roles include `station.P`. A public sentinel probe confirms the sentinel is present in `operator` and absent from `subject`. The subject view is the input source, not automatically the final MOA allowlist. Exclude raw station/checkpoint objects, arbitrary message fields, schedules and truth paths from the new boundary.
- **F6/F9:** the subject view has 30 points, including FI100, and controller mode, SP, OP, sample tick and control revision. Legacy exporters drop controller context. FI100 can be a good-quality extra current snapshot tag, but legacy lab-v2 does not require/use it, and the fixed five-tag history rejects it.
- **F7/F21:** current source quality is GOOD/BAD. Do not fabricate source reasons such as frozen or drift from evaluator truth. Preserve source quality separately from an MOA-derived range/validity classification based on declared public configuration.
- **F24:** legacy history allows 4–25 samples and 30–240 seconds; the exporter retains 13 samples at ten-second cadence. The kernel's built-in `trend_windows` covers only TIC201, TI312 and LIC503. It is not a ready-made complete U1 history feed. Build the new rolling history from allowlisted point samples, with explicit sample/byte limits.
- **F25:** existing wall-clock freshness and snapshot hashes do not establish that a result still refers to the current stream state. The new path needs declared stream identity, ordering, configuration/control revisions and a release-time comparison with its accepted current state. Keep simulation time, capture/ingestion time and processing time conceptually separate; exact wire fields await the build brief.
- **F2:** `scripts/validate.py` gives the whole suite a 120-second subprocess timeout and does not preserve partial output/final failure receipt on `TimeoutExpired`. This is an infrastructure defect, not evidence that the current suite exceeds 120 seconds on every machine.
- **F3:** `receipts/latest` is the original v0.1 bootstrap, not the current validation. The index needed updating. The script also defaults to that historical directory and allows overwrite; the next harness change must use fresh destinations and record explicit current pointers without rewriting old runs.
- **F4:** `EvidenceStore.append()` verifies the whole chain before inserting. Profile before changing it. No optimization has been made and no integrity guarantee has been weakened.
- **F22:** kernel commit `ca7d9e24b9cb5c6c7fb091ef06c6c4b4106149ec` explicitly says model commissioning remains pending. Deterministic replay must not be labeled physics validation.

The supplied speed, bank-size, trip-time and external benchmark figures were not reproduced during this intake. They remain source claims, not new measurements by this work.

## Work packages and gates

1. **C5 boundary first:** add a pinned, read-only observer with a recursive field allowlist and separate public configuration extraction. Verify that changes to forbidden fields, keys or future schedules cannot change the allowed projection. Do not expose evaluator or generation paths through tools or results.
2. **C6/C7 versioned contract:** add schema 1.2 separately, with bounded 1 Hz history, FI100, mode/SP/OP, explicit units and ranges, source quality plus derived validity, ordering and revision bindings. Dispatch explicitly by schema/profile so legacy validation keeps its present behavior. Settle the brief's clock, replay and resynchronization semantics before code.
3. **C8/C9 deterministic stream path:** add a provider-free entry point and separately identified dependency-scoped policy (`lab-v2-deps`, per the brief). Derive every displayed number from validated evidence and fixed templates. Bind results to the assessed state and withhold obsolete live results. Do not import the model loop or silently relabel lab-v2 cases.
4. **C1/C2/C3/C4 slice runner:** outside the simulator core, step the pinned kernel at 0.5 seconds and sample the public channel at the declared cadence. Separate generator/truth artifacts from the MOA channel physically and by API. Four scenario definitions, the invariance twin and T1–T11 remain required inputs.
5. **B7/B5 harness maintenance:** configurable validation timeout, timeout/partial-output receipts, fresh output directories and explicit receipt index. Profile A10 on synthetic logs with size and timing receipts; preserve tamper, truncation and restart tests before considering optimization.
6. **Interface review:** run the supplied T1–T11 and existing legacy suite, publish exact source/runtime/command receipts, then obtain the requested interface approval. Passing project tests is not independent controls review or kernel commissioning.

Later work remains separate: lab-v3 rules and human review; raw data-bank campaigns and prefix/checkpoint-aware splits; commissioning before final labels; and new frozen explanation-task evaluations. No private bank repository, finalized labels, model campaign, Ignition connection or plant-facing path is created by this intake.
